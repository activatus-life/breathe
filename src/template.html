Download this guide for Claude

You're about to save a copy of this whole guide in a form an AI assistant can read.

What you're getting

One file called and-breathe-build-guide.md. It holds every page of this guide as plain text. The .md on the end stands for Markdown, which is just a tidy way of writing plain text that Claude reads very easily.

The screenshots aren't in the file. Each one is replaced by a short description, and the file points back to the online guide at breathe-app-scope.vercel.app so you (or Claude) can look at them there.

How to use it

  1. Press Download the file. It lands in your Downloads folder.
  2. To ask questions about the app, open Claude, drag the file into the chat and ask away.
  3. To have the app built, pass the file to whoever is building it (or to Claude Code). It goes in the project folder as docs/build-guide.md.

You don't need to open the file yourself. If you do, you'll see ordinary text with a few # and * symbols in it. That's normal.
